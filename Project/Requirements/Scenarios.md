# Requirements Elicitation Scenarios

## S-01 — Submit Maintenance Request
**Primary Actor:** Student

A student notices a maintenance issue on campus, such as a broken air conditioner. The student submits a maintenance request by providing the issue location and a description of the problem.

## S-02 — Track Maintenance Request
**Primary Actor:** Student

A student checks a previously submitted maintenance request to view its current status and progress.

## S-03 — Assign Maintenance Request
**Primary Actor:** Facilities Administrator

A facilities administrator reviews a submitted maintenance request and assigns it to the appropriate maintenance staff member.

## S-04 — Update Maintenance Request Status
**Primary Actor:** Maintenance Staff

A maintenance staff member works on an assigned maintenance request and updates its status to reflect the progress or completion of the work.

## S-05 — Receive Status Notification
**Primary Actor:** Student

A student receives a notification when the status of their submitted maintenance request changes.
