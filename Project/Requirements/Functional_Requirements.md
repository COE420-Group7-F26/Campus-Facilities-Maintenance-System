# Functional Requirements

## Maryam Alteneiji Contributions

| FR ID | Functional Requirement | Source Scenario/Stakeholder | Contributor |
|---|---|---|---|
| FR-01 | The system shall allow students to attach a photo of the maintenance issue to a request. | S-01 / Student | Maryam Alteneiji |
| FR-02 | The system shall automatically record the date and time when a maintenance request is submitted. | S-01 / Student | Maryam Alteneiji |
| FR-03 | The system shall allow facilities administrators to prioritize maintenance requests based on urgency. | S-03 / Facilities Administrator | Maryam Alteneiji |
| FR-04 | The system shall allow maintenance staff to add repair notes to an assigned maintenance request. | S-04 / Maintenance Staff | Maryam Alteneiji |
| FR-05 | The system shall send a notification to the student when the status of their maintenance request changes. | S-05 / Student | Maryam Alteneiji |

## Shahad Alshamsi Contributions

| FR ID | Functional Requirement | Source Scenario/Stakeholder | Contributor |
|---|---|---|---|
