# Non-Functional Requirements

## Maryam Alteneiji Contributions

| NFR ID | Category | Non-Functional Requirement | Contributor |
|---|---|---|---|
| NFR-01 | Performance | The system shall display the maintenance request list within 2 seconds under normal operating conditions. | Maryam Alteneiji |
| NFR-02 | Security | The system shall automatically log out an inactive user after 15 minutes. | Maryam Alteneiji |
| NFR-03 | Usability | The system shall display clear validation messages when required maintenance-request information is missing. | Maryam Alteneiji |
| NFR-04 | Reliability | The system shall preserve submitted maintenance-request data if a page is refreshed after successful submission. | Maryam Alteneiji |
| NFR-05 | Maintainability | The system shall record application errors in a log with the date and time to support troubleshooting. | Maryam Alteneiji |
