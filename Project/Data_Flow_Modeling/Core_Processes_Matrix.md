# Exercise 3: Core Processes Matrix

| Process No. and Name | Input Data | Output Data | Rules |
|---|---|---|---|
| P1 – Manage Maintenance Requests | Maintenance Request Information; Request Information and Status | Submitted Request Details; Request Data (new/updated); Request Status Notification | The system receives maintenance request information, stores new or updated request data, and provides request information and status when needed. |
| P2 – Review and Prioritize Requests | Submitted Request Details; Maintenance Policies and Priority Criteria | Approved Requests and Priorities; Prioritized Requests | Submitted requests are reviewed and prioritized according to maintenance policies, urgency, and priority criteria. |
| P3 – Assign Maintenance Requests | Prioritized Requests; Work Progress Updates and Completion Details | Work Orders and Assignment Details; Request Status Updates; Assignment Details | Prioritized requests are assigned to appropriate maintenance staff. Assignment and status information is recorded and updated as work progresses. |
| P4 – Perform Maintenance and Update Repair Details | Maintenance Work Details | Work Completion Confirmation; Completed Maintenance Details; Status Update | Maintenance staff perform the assigned work and record repair details. Completed maintenance information and the updated status are recorded after the work is completed. |
| P5 – Track Request Status and Notifications | Status Update; Maintenance Records and History | Status Notifications and Updates; Reports and Notifications | The system tracks request status using maintenance records and status updates and provides appropriate notifications and updates. |
