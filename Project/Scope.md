# Project Scope

## Project Objective

The main goal of our Campus Facilities Maintenance System is to make it easier to report and manage maintenance problems around campus. Users will be able to submit a maintenance request and keep track of what is happening with it.

## Target Users

The main users of our system are:

- Students and university staff who want to report maintenance problems.
- Maintenance staff who will receive and work on the requests.
- Facilities administrators who will manage the requests and check their progress.

## In-Scope Features

Our system will include:

- User login.
- Submitting a maintenance request.
- Adding the location and description of the problem.
- Viewing and tracking submitted requests.
- Assigning requests to maintenance staff.
- Updating the status of a request.
- Notifications when the request status changes.

## Out-of-Scope Features

For the project, we won’t include:

- Automatic detection of maintenance problems using sensors.
- Maintenance equipment or inventory management.
- Online payments.
- Integration with outside maintenance companies.
- A separate mobile application.

## Major Deliverables

The main deliverables will be:

- A working version/prototype of the system.
- The source code.
- Project documentation.
- System design.
- Testing and results.
- Final project report.
