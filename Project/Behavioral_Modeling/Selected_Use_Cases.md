# Lab 6 - Exercise 1: Selected Major Use Cases

Project: Campus Facilities Maintenance System

The following four major use cases were selected from Lab 3 for UML Sequence Diagram modeling.

| Use Case ID | Use Case Name | Primary Actor | Purpose | Reason for Selection |
|---|---|---|---|---|
| UC-01 | Submit Maintenance Request | Student | Allows students to submit maintenance requests by providing the issue location and description. | Represents the main function of the system and involves interactions between students and maintenance requests. |
| UC-04 | Assign Maintenance Request | Facilities Administrator | Allows the administrator to assign a maintenance request to an appropriate maintenance staff member. | Demonstrates how requests are assigned and how the administrator interacts with maintenance staff and request assignments. |
| UC-20 | Record Repair Completion | Maintenance Staff | Allows maintenance staff to record the completion date and time after finishing a repair. | Represents an important maintenance activity and demonstrates how repair completion information is recorded. |
| UC-09 | Receive Status Notification | Student | Allows students to receive notifications when the status of their maintenance requests changes. | Demonstrates how the system communicates request updates to students through notifications. |

These use cases represent different stages of the maintenance request process and involve important interactions between system actors and objects.
