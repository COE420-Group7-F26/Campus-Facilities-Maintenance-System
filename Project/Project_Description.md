# Project Description

The Campus Facilities Maintenance System is designed to simplify the process of reporting and managing maintenance issues across the university campus. Students, faculty, and staff can report problems such as damaged equipment, electrical issues, plumbing problems, or other facility-related concerns.

Users can submit maintenance requests, specify the location and details of the problem, and track the status of their requests. Maintenance staff and administrators can view reported issues, assign maintenance tasks, update request statuses, and manage maintenance activities.

The main features include maintenance issue reporting, request tracking, status updates, issue categorization, and maintenance task management. The system aims to improve communication between campus users and maintenance staff and make the maintenance process more organized and efficient.
