# Process Model

## Selected Software Process Model

For our Campus Facilities Maintenance System, we chose the Incremental Model.

## Justification

We chose the Incremental Model because we can build our system in smaller parts instead of trying to finish everything at once. We can start with the main feature, which is allowing users to submit a maintenance request. After that, we can add other features like tracking the request, assigning it to maintenance staff, changing its status, and sending notifications. This model works well for our project because we can work on the important features first and then add more features as we continue developing the system.

## Drawbacks and Management

One drawback of the Incremental Model is that we need to plan the different increments properly before we start. It can also be difficult to integrate the different parts together, especially when we add more features. To manage this, we will decide what features will be included in each increment and make sure each part works properly before adding the next one. We will also test the system after adding new features to make sure everything still works together.
